## Python
- Respecter la structure réelle du projet.
- Préférer des fonctions ou modules simples à comprendre.
- Ne pas ajouter de dépendance Python sans raison valable.
- Si une dépendance est ajoutée, l'inscrire aussi dans le fichier requirements au bon format.
- Si un pyproject.toml est présent, le garder cohérent avec les dépendances réelles.
- Si un venv est utilisé, ne jamais supposer qu'il doit être versionné.
